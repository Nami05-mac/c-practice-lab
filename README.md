# C Practice Lab

An interactive, browser-based practice app for learning C fundamentals through short coding and output-prediction questions.

## Use it

Open `index.html` in a modern browser, or publish this folder with GitHub Pages. No build step or package installation is required.

## What it includes

- 54 practice questions across 11 topics
- A code editor with syntax highlighting and answer checking
- Hints and step-by-step walkthroughs
- Progress, drafts, notes, and theme preferences saved in the browser
- Responsive layout and several editor themes

## Data and hosting notes

This is the standalone HTML export of the C Practice Lab artifact from Claude. The app stores progress in the browser's local storage. Its optional Claude-hosted sync is available only inside Claude; outside Claude the app falls back to local storage, so progress remains local to that browser and device.

The page loads DM Sans, JetBrains Mono, and Newsreader from Google Fonts when internet access is available. The app otherwise runs without a server or third-party JavaScript libraries.
